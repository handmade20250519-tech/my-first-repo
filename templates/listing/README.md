# minneの商品画像の作り方(ぽち袋 データ版)

## ファイル
| ファイル | 使い方 |
|---|---|
| `guide_1_main.png` | 1枚目(一覧に出る画像)の配置ガイド。Canvaで背景に敷き、上に写真を置いたら消す |
| `guide_2_variants.png` | 2枚目(文字違い6種)の配置ガイド |
| `badge_download.png` | 「ダウンロード商品/紙の袋はお届けしません」のバッジ(背景は透明)。1枚目に必ず置く |
| `make_listing_guides.py` | 上の3つを作るプログラム |

## 画像の組み立て(1商品につき5枚)
1. **完成したぽち袋の写真+バッジ**(一覧に出る。いちばん大事)
2. **文字違い6種の一覧**(Canvaのデータを画像で書き出して並べる)
3. **作り方**(印刷 → 切る → 折る → 貼る。説明書の工程写真を使い回す)
4. **大きさが分かる写真**(手に持つ、定規を添える。「64×95mm」と文字を入れる)
5. **中身の一覧**(ZIPの中のPDF2つ。ファイル名とページ数)

## 1枚目のルール
- 正方形。Canvaで 2000×2000px のカスタムサイズ
- 絵は大きく。一覧では小さく表示されるので、動物の顔が分かる大きさにする
- 無地の明るい背景(白い紙や明るい木の机)、昼間の自然光。影が強く出ないよう、窓の近くで撮る
- **バッジを必ず置く。** 写真は完成した紙の袋なので、紙の袋が届くと誤解されないようにする(説明文の注意と同じ内容)
- 文字は少なく。入れるなら「印刷して作る ぽち袋」くらい

## 撮影のコツ
- 同じ場所、同じ時間帯、同じ向きで全部の犬種・猫を撮ると、ショップの一覧がそろって見える
- お札は写さない(大きさは手や定規で見せる)
- スマホは真上から。ゆがむときは少し離れてズームする

## 確かめること
