# ぽち袋の型(A4横・2枚どり)

| ファイル | 使い道 |
|---|---|
| `pochi_guide_A4.png` | Canvaで下敷きにする型。切る線・折る線・のりしろに加え、青い「文字の範囲」「絵を置く範囲」の目安が入っている |
| `pochi_lines_A4.png` | 売るデータに入れる線だけの版(背景が透明)。切る線・折る線だけ |
| `pochi_guide_A4.pdf` | 自分で試し刷りして、組み立てを確かめるための実寸の型 |
| `make_pochi_template.py` | 型を作り直すときのスクリプト(寸法を変えたいとき用) |

## 寸法
- 仕上がり: 64×95mm(一万円札を三つ折り、約53×76mmにして入る)
- 左右の折り返し: 35mmずつ(うしろで6mm重なる)
- ふた(上): 20mm、のりしろ(下): 25mm
- おもての安全域: 端から4mm内側(絵と文字はこの内側に置く)

## Canvaでの作り方
1. **デザインを作る:** 「カスタムサイズ」で 297×210mm(A4横)を作る。
2. **型を下敷きにする:** `pochi_guide_A4.png` をアップロードし、ページいっぱいに置いて「ロック」する。
3. **絵を置く:** 動物の絵を、青い「絵を置く範囲」に収まる大きさで置く。2枚どりなので、左右のおもてに1枚ずつ置く。
   - 絵の背景は白。おもてを白のままにするなら、背景を消す必要はない。
   - おもてに色を付けたい場合は、絵の背景を消す必要がある(Canvaの「背景除去」は有料プランの機能)。
4. **文字を入れる:** 青い「文字の範囲」に入れる(文字の入れ方は次の作業で決める)。
5. **売るデータに仕上げる:** 下敷きの `pochi_guide_A4.png` を消し、代わりに `pochi_lines_A4.png` をページいっぱいに置く。青い目安が消え、切る線・折る線だけが残る。
6. **書き出す:** 「PDF(印刷)」で書き出す。

## 試し刷りで確かめること
- `pochi_guide_A4.pdf` を**実寸(100%、拡大縮小なし)**で印刷し、切って組み立てる。
- 一万円札を三つ折りにして入れ、無理なく入るか。
- 家庭用のプリンターでふちなし印刷ができなくても、型は用紙の端から余白をとってあるので切れない。
