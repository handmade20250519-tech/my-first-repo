# ぽち袋の型(A4横・2枚どり)

| ファイル | 使い道 |
|---|---|
| `pochi_guide_A4.png` | Canvaで下敷きにする型。切る線・折る線・のりしろに加え、青い「文字の範囲」「絵を置く範囲」の目安が入っている |
| `pochi_print_A4.png` | **売るデータに入れる版(推奨)。** 組み立てたあと線が目立たない。切る線ははっきりした灰色で、型の外側だけに引いてある(線の上を切れば袋に線が残らない)。折る線は袋の上に引かずに型の外側の短い目印だけ。のりしろの印は、組み立てると②の下に隠れる①の端だけ(③には付けない。③は袋のうしろに見えるため) |
| `pochi_lines_A4.png` | 前の版。折る線が点線で袋の上に入るので、組み立てると線が見える。使わない |
| `pochi_guide_A4.pdf` | 自分で試し刷りして、組み立てを確かめるための実寸の型 |
| `make_pochi_template.py` | 型を作り直すときのスクリプト(寸法を変えたいとき用) |

## 寸法
- 仕上がり: 64×95mm(一万円札を三つ折り、約53×76mmにして入る)
- 左右の折り返し: 37mmずつ(うしろで10mm重なる)
- ふた(上): 20mm、のりしろ(下): 25mm
- おもての安全域: 端から4mm内側(絵と文字はこの内側に置く)

## Canvaでの作り方
1. **デザインを作る:** 「カスタムサイズ」で 297×210mm(A4横)を作る。
2. **型を下敷きにする:** `pochi_guide_A4.png` をアップロードし、ページいっぱいに置いて「ロック」する。
3. **絵を置く:** 動物の絵を、青い「絵を置く範囲」に収まる大きさで置く。2枚どりなので、左右のおもてに1枚ずつ置く。
   - 絵の背景は白。おもてを白のままにするなら、背景を消す必要はない。
   - おもてに色を付けたい場合は、絵の背景を消す必要がある(Canvaの「背景除去」は有料プランの機能)。
4. **文字を入れる:** 青い「文字の範囲」に入れる(文字の入れ方は次の作業で決める)。
5. **売るデータに仕上げる:** 下敷きの `pochi_guide_A4.png` を消し、代わりに `pochi_print_A4.png` をページいっぱいに置く。青い目安が消え、薄い切る線と、型の外側の折り目の目印だけが残る。
   - 折るときは、上下(または左右)の目印どうしを定規で結び、その線で折る。作り方の説明にもこのことを書く。
6. **書き出す:** 「PDF(印刷)」で書き出す。

## 試し刷りで確かめること
- `pochi_guide_A4.pdf` を**実寸(100%、拡大縮小なし)**で印刷し、切って組み立てる。
- 一万円札を三つ折りにして入れ、無理なく入るか。
- 家庭用のプリンターでふちなし印刷ができなくても、型は用紙の端から余白をとってあるので切れない。

# データ版(ダウンロード販売)の中身

## ZIPに入れるもの(1犬種・1猫柄につき1つのZIP)
| ファイル | 中身 |
|---|---|
| `(犬種名)_ぽち袋.pdf` | A4横・6ページ。どのページも同じ絵のぽち袋が2つ。文字だけが違う(下の表) |
| `作り方とご利用について.pdf` | `pochi_howto.pdf` の名前を変えたもの。全商品で共通 |

| ページ | 文字 |
|---|---|
| 1 | のしのみ |
| 2 | のし+おとしだま |
| 3 | のし+ありがとう |
| 4 | のし+おめでとう |
| 5 | のし+こころばかり |
| 6 | のしも文字もなし(手書き用。お見舞いなどにも使える) |

## Canvaでの作り方
1. 1ページ目を「のしのみ」で完成させる(型は `pochi_print_A4.png`)。
2. ページの「複製」で5ページ増やし、2〜5ページ目に文字を足す。6ページ目はのしを消す。
3. 「共有」→「ダウンロード」→ ファイルの種類「PDF(印刷)」、全ページを選んで書き出す。トリムマークと塗り足しはオフ。
4. 書き出したPDFの名前を `(犬種名)_ぽち袋.pdf` にする。

## ZIPにまとめる
- Windows: 2つのファイルを選んで右クリック →「圧縮先」→「ZIPファイル」(または「送る」→「圧縮(zip形式)フォルダー」)
- Mac: 2つのファイルを選んで右クリック →「2項目を圧縮」
- ZIPの名前は `(犬種名)_ぽち袋.zip`(例: `柴犬_ぽち袋.zip`)

## 説明書について
- `pochi_howto.pdf` の下にある「(ショップ名)」は、ショップ名が決まったら `make_instructions.py` の `SHOP` を書き換えて作り直す。

## 作り方の説明書(`pochi_howto.pdf`)の工程写真
- 3ページ構成: 1ページ目 = 印刷のしかた+工程1〜2、2ページ目 = 工程3〜5、3ページ目 = ご利用について。
- 各工程の左に写真の枠(横4:3、76×57mm)がある。写真が無いあいだは、点線の枠が表示される。
- 写真の差し替え方: `templates/pochi/photos/` に `step1.jpg` 〜 `step5.jpg`(.png も可)を置いて、`python3 make_instructions.py` を実行する。縦の写真や比率の違う写真は、枠に合わせて中央で切り取られる。
- 撮り方のコツ: 無地の明るい背景、真上から、手元だけを写す。工程ごとに向きをそろえる。

## 組み立ての注意(ユーザーの試作から)
- **売るデータには必ず `pochi_print_A4.png` を使う。** `pochi_guide_A4.png` や `pochi_lines_A4.png` で作ると、折り線の点線が袋の表に残って目立つ(試作で確認)。
- 折り線は、切り取った型の角(くびれている所)どうしを結べば正しい位置で折れる。袋の上に線はいらない。
- 貼るのはスティックのりか両面テープ。液体のりは、インクジェットの印刷が水分でにじむことがある。説明書と出品文にも書いた。
- ふた④は、袋の口に差し込んで閉じる。マーメイド紙など厚い紙で試したところ、元の型(ふたの付け根が袋と同じ幅64mm)では強く押し込む必要があり、しわが付いた。→ ふたの付け根を左右2mmずつ(60mm)、先を左右6mmずつ(52mm)細くした(`LID_IN`、`LID_TIP`)。
- **型を変えたので、Canvaで作ったデータは、下敷きを新しい `pochi_print_A4.png` に差し替えて書き出し直す。**
- 切る線が薄すぎて、印刷すると切る場所が分からなかった(試作で確認)。→ 灰色を濃くし(120,120,120)、太さ約0.4mmで型の外側だけに引くようにした。折る位置の目印も同じ濃さにした。
- 試作(ワイヤーダックス、マーメイド紙): 袋の上に点線がないので、仕上がりがきれい(ユーザー評価)。切り線が袋のふちに少し残るかどうかは、切る人の手元しだいなので許容する(ユーザー判断)。**袋の上に折り線を引かない今の形で確定。**
- ふたを細くしても、マーメイド紙では少し縮めないと差し込めなかった。これ以上細くすると形が不自然になる。→ **差し込み式はやめ、ふたはうしろへ折ってシールや両面テープで留める方式で確定**(ユーザー判断)。ふたの細い形はそのまま残す。
- うしろの重なりが6mmでは狭く、極細の両面テープでもはみ出した(猫の試作)。→ 左右の折り返しを35mm→37mmにして、重なりを10mmにした。のりしろの印も8mm幅にした。袋の表の位置は、1枚目が約0.7mm左、2枚目が約0.7mm右にずれるだけなので、絵の置き直しはいらない(安全域4mmの中に収まる)。
