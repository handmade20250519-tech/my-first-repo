## 1種類ずつの出品の流れ(いまのやり方)
1. ユーザーがGeminiで絵を作り、Canvaで6ページを作る(のりしろ・型は `templates/pochi/`)
2. ユーザーが6ページのスクリーンショットを送る(2ページ分を1枚にまとめた画像のときは、左右に切って使う)
3. 出品文: `docs/minne-pochi-listing-<名前>.md` を作る。いちばん新しい形の見本は `minne-pochi-listing-chipoo.md`(犬)、`minne-pochi-listing-cat-chatora.md`(猫)
   - 作品名: 「(犬種・猫の柄)のぽち袋 (あるある)｜お年玉・お礼に｜印刷して作るダウンロード版 のし付き6種(AIを用いた作品)」
   - 価格500円。タグは5つ(犬種名/別名/ぽち袋/お年玉袋/犬好き or 猫好き)
   - 説明文の「絵は、墨と淡い水彩で…」の段落の次に、必ずこの一文: `※画像は『かんたん4ステップ』以外、AIで作ったイメージ画像です。袋の絵柄は実際の商品と同じです。`
   - 日本の呼び方と違う英語の名前(Maltipoo、Chipoo)は、その次に名前の説明を入れる(ユーザーの希望)
   - 絵を見て、あるあるの文が絵と合っているか確かめる(合わなければ文を絵に合わせる)
   - 購入時の注意点は柴犬と同じ。ファイル名 `<名前>_pochi.pdf`、`howto.pdf`、ZIP `uchinoko-aruaru_<名前>_pochi.zip`
4. 商品画像: `shop/make_<名前>_images.py` を前の種類からコピーして画像の番号を変える → `listing_<名前>_1.jpg`(デザイン見本)、`listing_<名前>_3.jpg`(6種類)。3枚目は共通の `listing_shiba_4.jpg`(作り方)
5. 場面写真(商品紹介の画像):
   - Geminiのプロンプトは**袋を真っ白(blank)にして作ってもらう**。Geminiは絵を描き変えてしまうので、本物の絵はあとで貼る
   - 貼るのは `shop/make_scene_blank.py`(SCENESに画像と袋の四隅を足す)。注記入りは `shop/add_ai_note.py`
   - 袋が大きすぎるときは、**Geminiに「袋だけ20%小さく、ほかはそのまま」と頼んでもらう**(こちらで小さくするとうしろの景色が不自然になって失敗した)
   - Geminiの画面のボタン(編集・共有)が写っていたら、切り取って外す(make_scene_blank.py の CROP)
   - 画像の上に「※AIで作ったイメージ画像です。袋の絵柄は実際の商品と同じです。」を入れた版も作る
6. はみ出す構図(超大型犬など): `shop/check_wraparound.py` で組み立てたときに絵が隠れないか確かめる。底ののりしろを21mmにした型(`templates/pochi/*_b21.*`)がある。グレート・デーンで使用
