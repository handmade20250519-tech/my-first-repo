# Canvaの共通マスター(6ページ)の作り方と使い方

目的: 動物ごとに文字を入れ直さず、イラストと動物名だけを差し替えて6ページを作る。仕上がりと印刷サイズは今と同じにする。
作業はユーザーのCanvaで行う(Claudeは操作できない)。Canvaのメニューの名前は、画面によって少し違うことがある。

## 最初に1回だけ: マスターを作る(20〜30分)
1. いちばん新しい動物(チワワ)のデザインを開き、「ファイル」→「コピーを作成」。名前を「ぽち袋マスター」にする
2. イラストを「フレーム」に入れる(差し替えを1回のドラッグにするため)
   - イラストを1つ選び、「配置」で幅・高さ・位置(X・Y)を書き留める
   - 「素材」→「フレーム」で正方形のフレームを置き、幅・高さ・X・Yを書き留めた数字と同じにする
   - イラストをフレームの上にドラッグして入れ、もとのイラストは消す
   - 12か所(6ページ×2袋)すべてで同じことをする(1か所作ってコピーし、ほかのページに貼りつけてもよい。貼りつけたあと、X・Yが同じか確かめる)
3. 6ページの文字(のし・おとしだま・ありがとう・おめでとう・こころばかり・文字なし)は、そのまま残す
4. 終わったらPDFでダウンロードしてClaudeに送る。`shop/make_from_pdf.py` で、袋が64×95mmのままか、6ページそろっているかを確かめる

## 動物を足すたび(5〜10分)
1. 「ぽち袋マスター」を開き、「ファイル」→「コピーを作成」。名前を動物名にする(マスター自体は変えない)
2. 新しいイラスト(背景を消したもの)を、12個のフレームに1つずつドラッグする
   - フレームは、絵を枠いっぱいに広げる。正方形の絵なら切れない。正方形でない絵は端が切れることがあるので、フレームをダブルクリックして位置を直す
3. 動物名は「検索と置換」でまとめて変える(例: Chihuahua → Samoyed)。袋の12か所と、ページ左下の名前が一度に変わる
   - 「検索と置換」が見つからないときは、12か所を1つずつ書き直す
4. 大型犬など、はみ出す絵は、今までどおり1か所ずつ大きさと位置を直す
5. PDFでダウンロードして、そのまま送る

## 有料プランのとき(試してみる価値あり)
Canvaの「一括作成」では、イラストと名前を表に書くと、6ページを自動で作れることがある。お使いのプランで使えるかは、まだ確かめていない。

## 注意
- マスターを直接書きかえない。いつも「コピーを作成」してから使う
- 文字の位置や大きさを変えたいときは、マスターを直す(次の動物から全部そろう)
