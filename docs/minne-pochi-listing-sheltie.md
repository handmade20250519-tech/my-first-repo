```
玄関に並んだ家族のスリッパのそばに、きちんとふせて、みんながそろっているか見守り中。家族のあとをついて回る、まじめでやさしい「見守り係」。
シェルティと暮らす人なら、きっと毎日見ている「家族の番」の姿を、ぽち袋とポストカード、あけおめ動画にしました。

お年玉やちょっとしたお礼を渡すとき、袋を見た相手が「うちの子もこれやる!」と笑ってくれたら。そんな一枚になればうれしいです。

動画の見本(YouTube):(ここにリンク)
```
