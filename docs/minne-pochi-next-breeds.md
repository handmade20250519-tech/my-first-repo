# 次に増やす犬種・猫種の候補(犬10・猫5)

24種類をminneに出品したあと、ユーザーの依頼で選んだ。すでにある種類(指示文あり)は除いた。
選び方: 日本で飼っている人が多い(買う人が多い)種類と、レア(ほかの店にない、ファンが探している)種類をまぜた。
**minneの売れ行きのデータは見ていない。** 作る前に、minneで「(犬種名) ぽち袋」「(犬種名) グッズ」を検索し、ほかの店の数と人気を確かめる。

## 犬(10種)
### 人気(6種)
| 犬種 | あるあるの案 |
|---|---|
| パピヨン | 大きな蝶の耳をぴんと広げて、遠くの物音に全集中 |
| キャバリア・キング・チャールズ・スパニエル | 甘えんぼ。ひざにあごをのせて、うるうるの目で見上げる |
| ラブラドール・レトリーバー | 食いしんぼう。ごはんの器を自分でくわえて持ってくる |
| パグ | いびきが大きい。仰向けで、鼻ちょうちんが出そうな寝顔 |
| ミニチュア・ピンシャー | 小さいのに強気。自分より大きいものに胸を張って立ち向かう |
| シェットランド・シープドッグ(シェルティ) | 家族のあとをついて回る「見守り係」。散歩で家族が離れると、まとめようとする |

### レア(4種)
| 犬種 | あるあるの案 |
|---|---|
| 秋田犬 | もふもふでどっしり。雪の日は外から帰ってこない |
| ベドリントン・テリア | 子羊そっくりの見た目。羊とまちがえられて、本人はきょとん |
| 甲斐犬 | 虎毛(とらげ)。ツンデレで、飼い主にだけしっぽを振る |
| 狆(ちん) | 日本の古い犬。目を大きく見開いた上品な顔で、くるくる回る「狆くるい」 |

## 猫(5種)
| 猫 | 種類 | あるあるの案 |
|---|---|---|
| サビ猫 | 毛柄(人気・ファンが多い) | 顔の模様がまだらで、表情が読めない。本人はとても甘えんぼ |
| 白猫 | 毛柄(人気) | 黒い服にだけ毛がつく。黒いセーターの上でくつろぐ |
| ノルウェージャン・フォレスト・キャット | 猫種(人気) | 大きくてふさふさ。冬毛でまんまるになる |
| ロシアンブルー | 猫種(人気) | 「ボイスレス・キャット」。鳴かずに、口だけ「にゃ」の形 |
| スフィンクス | 猫種(レア) | 毛がない。毛布や服にくるまって、ぬくぬく |

## 気をつけること
- 秋田犬・甲斐犬・狆は、ファンが毛色や顔の形にこだわる。キンカチョウと同じく、顔だけのテスト画像で描けるか確かめてから場面を作る
- スフィンクスは、絵にすると好みが分かれる。かわいく描けるか、テスト画像で確かめる
- 白猫は白い紙の上なので、サモエドと同じく細い墨の線で形を出す
