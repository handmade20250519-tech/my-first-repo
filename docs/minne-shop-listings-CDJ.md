## 1. 出品の形(意見)

### おすすめ: 絵柄ごとに3つの商品に分け、判型(色紙/掛軸)は各商品の中で選べるようにする

**理由**
1. **検索の入口が3つになる。** 「椿 メジロ」「鶴 長寿」「未年 羊」は、探す人も時期も違う。1つの商品にまとめると、商品名とタグを1つの絵柄にしか合わせられない。
2. **一覧の画像で絵が伝わる。** 一覧に出るのは1枚目の画像だけ。3つの絵柄を1枚に並べると、どの絵も小さくなって負ける。
3. **どの絵が売れるかが分かる。** お気に入り数とレビューが絵柄ごとにたまるので、次に作る絵を証拠で決められる(証拠主義の続き)。
4. **判型は同じ絵の違いなので、商品の中で選ばせる。** 色紙と掛軸を別の商品にすると、同じ絵が2枚並んで棚が単調になる。

**確認が必要なこと(未確認)**
- minneの出品画面で、判型ごとに価格を変える選択肢(オプション)が設定できるか。**できない場合**は、色紙と掛軸は値段の差が大きいので、次の形に切り替える。
  - 色紙3商品と掛軸3商品の、計6商品にする。商品数が少ないショップなら、6点並んでも多すぎない。
  - 掛軸の商品ページで「色紙版もあります」と案内し、行き来できるようにする。

### ショップを「ひとつの揃い」に見せる工夫
- 3点とも地は同じ生成りの和紙で、朱印は一つだけ。この共通点をシリーズ名で打ち出す。
  - シリーズ名の案: **「朱印ひとつの和紙絵」**
- 商品名の先頭を「朱印ひとつの和紙絵|」でそろえる。
- 各説明文の最後に、ほかの2点を短く紹介する。
- 1枚目の画像は、3点とも同じ撮り方(和室の壁や床の間に掛けた想定の写真風の画像)で統一する。

## 2. 生成済みの画像を色紙と掛軸に合わせる

元の画像は縦長の2:3(ポスター用)。どの絵も上半分が空いているので、**絵を切らずに紙を足す**方法で両方の判型を作る。

| 判型 | 比率 | やり方 | 解像度 |
|---|---|---|---|
| 色紙 | 約8:9(ほぼ正方形) | 左右に和紙の地を足して横に広げる | 元の縦4096pxを色紙の高さ272mmに当てると約380dpi。十分 |
| 掛軸(本紙) | 約1:2.5 | 上に和紙の地を足して縦に延ばす | 元の横約2730pxを本紙の幅30cmに当てると約230dpi。掛軸は離れて見るので実用範囲 |

**紙を足すときの注意**
- 無地の色で塗り足すと、和紙の繊維の質感が途切れて継ぎ目が見える。Geminiで次のように頼むか、画像編集ソフトの「生成拡張」機能を使う。

```
Extend the canvas of this image. Keep the existing painting exactly as it is, with no changes. Fill the new area only with the same warm washi paper background and the same subtle paper fiber texture, with no seams. Do not add any new objects, plants, animals, text or marks.
```
- 色紙に合わせて左右に足す場合は、次の点に注意する。
  - **C**は椿の枝が左端から入っている。左に紙を足すと、枝が画面の途中で切れて見える。**左は足さずに右だけ足す**か、Geminiに枝の続きを描かせる(「continue the camellia branch naturally to the new left edge」を足す)。
  - **J**は朱印が左下にあり、左右に紙を足すと端から離れる。問題が無いかを確認する。
- 掛軸に合わせて上に足すと、絵が本紙の下半分に寄る。これは掛軸では自然な配置なので、そのままでよい。

**生産支援で確認すること(未確認)**
- 色紙に直接印刷できる業者があるか。
- 印刷した本紙を掛軸に仕立ててくれる業者があるか。1本から頼めるか、納期と原価はどれくらいか。
- 本紙の幅(30cm前後)と、表装(布の色)を選べるか。表装の色は3点とも同じ落ち着いた色でそろえる。

## 4. 価格の考え方

- **色紙:** minneで見つけた還暦祝いの色紙は、1,100円(書)〜3,600円(手描き)。ただし、どちらも手書きの品。印刷の色紙は、**2,200〜2,800円**から始め、出品後2週間のお気に入り数を見て調整する。
- **掛軸:** 印刷と仕立ての原価が分からないため、**価格はまだ決められない**。業者の見積りが出たら「原価×2.5〜3倍」を目安にし、同じ種類の印刷掛軸の相場と比べて決める。
- 3つの絵柄は同じ価格にそろえる。シリーズとして比べやすくするため。
