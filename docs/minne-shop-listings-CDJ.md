## 1. 出品の形(意見)

### おすすめ: 絵柄ごとに3つの商品に分け、判型(色紙/掛軸)は各商品の中で選べるようにする

**理由**
1. **検索の入口が3つになる。** 「椿 メジロ」「鶴 長寿」「未年 羊」は、探す人も時期も違う。1つの商品にまとめると、商品名とタグを1つの絵柄にしか合わせられない。
2. **一覧の画像で絵が伝わる。** 一覧に出るのは1枚目の画像だけ。3つの絵柄を1枚に並べると、どの絵も小さくなって負ける。
3. **どの絵が売れるかが分かる。** お気に入り数とレビューが絵柄ごとにたまるので、次に作る絵を証拠で決められる(証拠主義の続き)。
4. **判型は同じ絵の違いなので、商品の中で選ばせる。** 色紙と掛軸を別の商品にすると、同じ絵が2枚並んで棚が単調になる。

**確認が必要なこと(未確認)**
- minneの出品画面で、判型ごとに価格を変える選択肢(オプション)が設定できるか。**できない場合**は、色紙と掛軸は値段の差が大きいので、次の形に切り替える。
  - 色紙3商品と掛軸3商品の、計6商品にする。商品数が少ないショップなら、6点並んでも多すぎない。
  - 掛軸の商品ページで「色紙版もあります」と案内し、行き来できるようにする。

### ショップを「ひとつの揃い」に見せる工夫
- 3点とも地は同じ生成りの和紙で、朱印は一つだけ。この共通点をシリーズ名で打ち出す。
  - シリーズ名の案: **「朱印ひとつの色紙絵」**(9.で「和紙絵」から変更)
- 商品名の先頭を「朱印ひとつの色紙絵|」でそろえる。
- 各説明文の最後に、ほかの2点を短く紹介する。
- 1枚目の画像は、3点とも同じ撮り方(和室の壁や床の間に掛けた想定の写真風の画像)で統一する。

## 2. 生成済みの画像を色紙と掛軸に合わせる

元の画像は縦長の2:3(ポスター用)。どの絵も上半分が空いているので、**絵を切らずに紙を足す**方法で両方の判型を作る。

| 判型 | 比率 | やり方 | 解像度 |
|---|---|---|---|
| 色紙 | 約8:9(ほぼ正方形) | 左右に和紙の地を足して横に広げる | 元の縦4096pxを色紙の高さ272mmに当てると約380dpi。十分 |
| 掛軸(本紙) | 約1:2.5 | 上に和紙の地を足して縦に延ばす | 元の横約2730pxを本紙の幅30cmに当てると約230dpi。掛軸は離れて見るので実用範囲 |

**紙を足すときの注意**
- 無地の色で塗り足すと、和紙の繊維の質感が途切れて継ぎ目が見える。Geminiで次のように頼むか、画像編集ソフトの「生成拡張」機能を使う。

```
Extend the canvas of this image. Keep the existing painting exactly as it is, with no changes. Fill the new area only with the same warm washi paper background and the same subtle paper fiber texture, with no seams. Do not add any new objects, plants, animals, text or marks.
```
- 色紙に合わせて左右に足す場合は、次の点に注意する。
  - **C**は椿の枝が左端から入っている。左に紙を足すと、枝が画面の途中で切れて見える。**左は足さずに右だけ足す**か、Geminiに枝の続きを描かせる(「continue the camellia branch naturally to the new left edge」を足す)。
  - **J**は朱印が左下にあり、左右に紙を足すと端から離れる。問題が無いかを確認する。
- 掛軸に合わせて上に足すと、絵が本紙の下半分に寄る。これは掛軸では自然な配置なので、そのままでよい。

**生産支援で確認すること(未確認)**
- 色紙に直接印刷できる業者があるか。
- 印刷した本紙を掛軸に仕立ててくれる業者があるか。1本から頼めるか、納期と原価はどれくらいか。
- 本紙の幅(30cm前後)と、表装(布の色)を選べるか。表装の色は3点とも同じ落ち着いた色でそろえる。

出典: [WAVE 色紙印刷](https://www.wave-inc.co.jp/products/shikishi.html)(ページ本体はこの環境から開けないため、検索結果の抜粋とユーザーの確認による)

| 項目 | 分かっていること |
|---|---|

| 紙 | 画仙または奉書 |
| 単価 | 1枚600円弱(ユーザーが確認) |
| 注文単位 | ユーザーの確認では10枚単位。一方で、検索結果には「1部から注文可能・当日出荷」とある → **1枚から頼めるか要確認** |

### 判断
- 大色紙が標準サイズ(273×242mm)なので、設計どおりに作れる。**候補として良い。**
- 紙は**画仙**を選ぶ。墨のにじみを描いた絵には、画仙の質感のほうが合う。
- 利益の目安(販売価格2,500円の場合): 販売価格2,500円 − 原価600円 − minne手数料(約10%) − 梱包材(約150円) ≒ **約1,500円**。送料は別にもらう前提。

### 注文前に確かめること
1. **1枚から頼めるか。** 頼めるなら、まず3絵柄を1枚ずつ試し刷りする。
2. **背景の和紙色を印刷するか、紙の地を生かすか。** 画仙はもともと白っぽい紙なので、生成りの地を全面に印刷すると、本物の紙の質感の上に「印刷した紙の質感」が重なる。次の2通りを試し刷りで比べる。
   - (a) 画像のまま印刷する(生成りの色が出る)
   - (b) 背景を抜いて絵だけを印刷する(画仙の白い地が見える)
3. **印刷できる範囲。** 色紙の端(金の縁取りがある場合はその部分)まで印刷できるか、端に白い余白が残るか。
4. **入稿データの条件。** 解像度、カラーモード(RGBかCMYKか)、塗り足しの有無。
5. **1枚ずつ袋に入れて届くか。** そのまま発送に使えるかどうか。

### 10枚単位の場合の考え方
- 3絵柄を10枚ずつ頼むと、約18,000円分の在庫を持つことになる。
- 最初は、**季節が先に来るJ(お正月)を10枚、CとDは試し刷りの結果を見てから**にする。
- 在庫を持つと、発送までの日数を「1〜3日」に縮められる。贈り物を探す人には強い売りになる。

## 8. 判型の見直し(業者比較を受けて)

### ユーザーが比べた業者
- 掛軸の仕立て: [アワガミ](https://awagami.jp/pages/kakejiku)、[タニグチ](https://www.taniguchi.co.jp/direct-order/kakeziku.html) → 単価が高すぎて現実的でない
- 和紙への印刷: [インクアート](https://www.inkart.jp/lineup/washi/)、[フォトプリ(アワガミ楮紙)](https://photopri.com/products/awagami-kouzo) → どちらも単価がとても高い
- 色紙の印刷: WAVE(1枚600円弱)。1枚から頼める業者もある

### 結論: 最初は色紙1本に絞る。掛軸はやめる
1. **色紙そのものが和紙の地を持っている。** WAVEで画仙を選べば、和紙専用の印刷を頼まなくても和紙の風合いが出る。高い和紙印刷と比べて、原価の差ほどの見た目の差は出にくい(試し刷りで確かめる)。
2. **掛軸の代わりに「色紙掛け」を選択肢にする。** 色紙掛けは、色紙を差し込んで床の間や壁に掛軸のように吊るす道具で、既製品として広く売られている。
   - 出品の選択肢: 「色紙のみ」/「色紙+色紙掛け」
   - 色紙掛けは既製品を仕入れて同梱する。自分の作品ではないので、説明文には「色紙掛けは既製品です」と明記する
   - 色紙掛けの仕入れ値と、送料が上がる分(箱が大きくなる)を確認してから価格を決める
3. **在庫を抱えない。** 1枚から頼める業者を使い、受注生産で始める。売れ筋が分かってから、まとめて頼んで原価を下げる。

### 出品の形(更新)
- 3絵柄(C・D・J)を別々の商品にする(1.の考えは変わらない)
- 各商品の選択肢は「色紙のみ」「色紙+色紙掛け」の2つ
- 商品名とタグの「掛軸」は「色紙掛け」に置き換える(掛軸を売らないのに掛軸と書かない)

### 次に確かめること
- 1枚から頼める色紙業者とWAVEの比較(単価、画仙の有無、納期、送料)
- 色紙掛けの仕入れ先と仕入れ値
- 試し刷り: 背景の生成りを印刷する版と、背景を抜いて紙の地を生かす版の比較

5. **お客さんへの直送。** 業者から購入者へ直接送れるか。できる場合、業者の納品書や価格表が同封されないか。直送できれば、在庫も発送作業も持たずに済む。

## 10. 確認結果と入稿・発送の方針

### ユーザーが確認したこと
| 項目 | 結果 |
|---|---|
| 色紙(L)の寸法 | Canvaで寸法に合わせて作り直して入稿するので問題なし |
| 販売してよいか | 業者のチャットで「お客様のデザインなら、minneなどで自由に販売できる」と回答あり |
| 入稿のしかた | 業者指定のAffinity(デザインソフト)を使って入稿する |
| 直送 | 使わない。メッセージカードを添えて自分で梱包・発送する |
| 「385円〜」の条件 | **未確認**(1枚だけ頼んだときの単価、送料、納期) |

### 販売の可否について
- 業者の回答はAIチャットによるもので、「正確性を保証しない」と但し書きがある。
- 回答画面のスクリーンショットを保存しておく。念のため、問い合わせフォームで人の担当者からも同じ答えをもらっておくと安心。

### 入稿の注意(Canva → Affinity)
- **塗り足し:** 背景の生成りの地は、仕上がり線の外まで延ばす(幅は業者の指定に従う。一般的には3mm程度)。レビューにあった「白い余白」を防ぐため。
- **安全域:** 羊・鳥・朱印は、仕上がり線から5mm以上内側に置く。
- **書き出し:** Canvaからは最高画質のPNGか「PDF(印刷)」で書き出す。画像を縮めて小さくしない。
- **色:** 印刷用の色(CMYK)に変えると、生成りと朱がくすむことがある。Affinityの画面で色が大きく変わったら、試し刷りで確かめてから本番に進む。

### 自分で梱包・発送する場合
- **良い点:** 業者の納品書が入る心配がない。メッセージカードで作品の物語を手渡しできる。
- **メッセージカードの案**(絵に文字を入れないぶん、言葉はカードで届ける):
  - 表: 作品名と朱印の意味(例: 「鶴の親子 — 朱印『寿』は、長く健やかにという願いの一字です」)
  - 裏: 贈り物用に、購入者が一言書ける空欄。「贈り物用カードを付ける」を選択肢にする
- **発送方法:** 色紙(L)は緩衝材と厚紙で挟むと大きくなるので、梱包した実物の寸法と厚さを測ってから決める。
  - 色紙のみ: 薄い発送方法に入るかを確かめる(レターパックなど)
  - 色紙+色紙掛け: 箱が必要になる(宅配便のコンパクトサイズなど)
- **発送までの日数:** 業者の納期 + 自分の梱包1〜2日 + 余裕1日。業者の納期が分かったら確定する。
