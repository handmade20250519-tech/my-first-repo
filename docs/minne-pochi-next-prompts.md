# 次の15種類の絵の指示文(Gemini用)

ユーザーが選んだ犬10種・猫5種(`minne-pochi-next-breeds.md`)の絵の指示文。見出しの下の文を、そのまま全部コピーしてGeminiに貼る。

## これまでの直しを最初から入れた
- ほっぺの赤みなし(三毛・人間のようだった)/太らせない(三毛・スコティッシュ)/怖い顔にしない、歯や牙を見せない(三毛・チワワ)
- しっぽは自然な長さで体に沿わせる(三毛)/顔の向きを自然に(ラグドール)/人・手・腕を描かない(ブリティッシュ)
- 猫は、キジトラでうまくいった猫の目の指定(アーモンド形、細い墨のアイライン)を全部に入れた
- 画風の段落の「ほっぺの赤み」の例を消した(ひな形には残っていたため)
- 生成後に、名前のつづりを必ず確かめる
