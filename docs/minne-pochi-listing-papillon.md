```
蝶の羽のような大きな耳を、ぴんと広げて。遠くで小さな物音がすると、ぴたりと動きを止めて全集中。小さな体で、聞きのがすまいと耳をすませる姿がいじらしいのです。

■ 作り方
━━━━━━━━━━
```
