## 説明文
```
名前を呼ぶと、くりっとした目でこちらを見て、こてんと首をかしげる。「なあに?」のその顔が見たくて、つい何度も呼んでしまいます。
チワプーと暮らす人なら、きっと毎日見ている「首かしげ」を、ぽち袋にしました。

お年玉やちょっとしたお礼を渡すとき、袋を見た相手が「うちの子もこれやる!」と笑ってくれたら。そんな一枚になればうれしいです。

絵は、墨と淡い水彩で描いたような雰囲気に仕上げました。ぽち袋という和の袋に合うように、落ち着いた色にしています。

※画像は『かんたん4ステップ』以外、AIで作ったイメージ画像です。袋の絵柄は実際の商品と同じです。

袋に入れた名前は、英語の「Chipoo(チプー)」です。日本では「チワプー」と呼ぶのが一般的ですが、英語ではチワワ(Chihuahua)を短く「Chi」と呼び、プードル(Poodle)と合わせて「Chipoo」と呼びます。
```
