# 2027年干支「未」 床の間・還暦祝いの一枚 設計書(静けさ)

## 狙い(STEP3の再回答。これまでの案とは切り離して考え直した)
- 飾る人と場所: 50〜60代。実家の床の間や和室。または親への贈り物(未年生まれの還暦祝いを含む)
- 気分: 静けさ。余白を大きく取り、色は暖かい色にする
- 文字: 絵だけで勝負する。文字は落款風の朱印だけ

## 考え直した出発点
1. **床の間に掛けるのは、ポスターではなく色紙か掛軸。** 50〜60代の和室に合わせ、判型から考え直した。主力は色紙(242×272mm)にし、掛軸版も用意する。
2. **2027年は丁未(ひのと・ひつじ)の年で、1967年(昭和42年)も同じ丁未。** 1967年生まれの人は2027年に満60歳になり、生まれた年とまったく同じ干支がめぐってくる「本卦還り(還暦)」を迎える。これを物語の芯にする。
3. **円相は、床の間の掛物として昔からある定番の形。** 還暦は「暦が一巡して還る」こと。一巡する円と羊を組み合わせる。
4. **還暦の贈り物として縁起の悪い読まれ方を避ける。** 夕日や落日は使わない。羊の目は閉じず、穏やかに開けておく(眠り=終わりと受け取られないため)。

## STEP4 デザイン設計

### コンセプト
**実家の床の間で眺める、六十年で一巡りする円と、静かに佇む羊の一枚**

(作品名の案: 「還る円(かえるえん)」。画面には入れない)

### デザイン案
| 項目 | 内容 |
|---|---|
| モチーフ | 一筆で描いた大きな円相と、その内側の底に脚をたたんで静かに座る成羊1頭 |
| 円相 | 弁柄色(暖かい赤茶)。描き始めは太く濃く、描き終わりはかすれて消えていく。右下に切れ目を残し、「終わりではなく、また始まる」を表す |
| 羊 | 暖かい薄墨で、少ない筆数で描く。羊毛は、紙よりわずかに明るい胡粉の白をのせて浮かび上がらせる。目は穏やかに開け、正面からやや右を見る |
| 配色 | 地は鳥の子色(#EDE0C8)の和紙。円相は弁柄(#9A4E36)。羊は暖かい薄墨(#7A6E62)と胡粉(#F6F0E4)。朱印は朱(#C8553D)。弁柄と朱は色みを分け、朱印が埋もれないようにする |
| 構図 | 円の直径は画面幅の約60%で、中心よりやや上に置く。羊は円の内側の底、幅の約18%。円の内側はほとんど空ける |
| 余白 | 円の内も外も余白。墨と色が乗るのは画面の15%程度 |
| 朱印 | 左下、円の外に1つ。印面は縦書きの篆書風「丁未」二字。1967年と2027年の両方を指す |

### 勝負できる理由
- **一覧の小さな画像でも伝わる。** 暖かい大きな円は、スマホのサムネイルでも一目で分かる。
- **床の間の作法に沿っている。** 円相は掛物の定番なので、年配の方の和室に置いても浮かない。
- **他にない物語がある。** 「生まれた年と同じ丁未がめぐってくる」は2027年だけの物語で、1967年生まれへの贈り物に強い。
- **名前を入れないので、受注生産の手間が増えない。**

## 改訂: 円相をやめる

### ユーザーの指摘
- 円を描いた赤(弁柄)が血の色に見える
- 座っている羊を円が取り囲んでいる意味が分からない
- 抽象的なもので意味を持たせなくてよい。穏やかな印象の絵がよい
- 円はやめる

→ 上の「還る円」案は**不採用**。

## 改訂2: 二頭の距離(色紙版)

### ユーザーの指摘
- 日本の老夫婦は、あまりベタベタくっつかない。羊同士をもう少し離す
- それでも、お互いを思い合っている構図にする

### 変更点
| 項目 | 変更前 | 変更後 |
|---|---|---|
| 距離 | 寄り添い、頭を傾ける | 羊の体の半分ほど離して座る。体は触れない |
| 思い合い | 頭を相手に傾ける | **二頭が同じ白梅を見上げている。** 体の向きはわずかに相手の側へ開き、並んで同じものを眺める |
| 並び | 横並び | 一頭が少し手前、もう一頭が少し奥。鏡に映したような左右対称にしない |
| 余白 | 枝と羊の間は空白 | 同じ空白が、二頭の視線が通る道になる(右下の羊から左上の梅へ) |
